# Movie Ticket Booking Management Application

Pega Academy - National Internship Program (NIP) 2026
Pega Platform Project

## Overview
CineWave Entertainment manages movie ticket bookings across multiple theatres. This application, built on Pega Platform, allows customers to submit ticket booking requests, checks seat availability, calculates cost, captures confirmation, processes the booking, and notifies the customer.

## Features Implemented
- Case type: Movie Ticket Request with 5 stages (Booking Intake, Seat Evaluation, Customer Decision, Booking Fulfillment, Booking Confirmation)
- Movie and Show reusable data objects
- Seat availability check and total cost calculation
- Customer confirm/cancel decision
- Seat allocation and Ticket ID generation
- Queue routing by Show Type (Premium/Standard)
- Email notification on booking confirmation
- SLA: 1-day goal, 2-day deadline

## Tech Stack
- Pega Platform (Community Edition)
- Pega Blueprint for application design
